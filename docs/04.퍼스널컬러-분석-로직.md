# 퍼스널컬러 분석 로직

## 현재 방식

현재 구현은 학습형 AI 모델이 아니라 OpenCV 얼굴 검출과 색 공간 계산을 이용한 체험용 분석 방식입니다.

1. 얼굴 이미지에서 가장 큰 정면 얼굴을 찾습니다.
2. 머리카락, 눈, 입술 영향을 줄이기 위해 이마와 양 볼 영역을 선택합니다.
3. 피부색 후보 픽셀을 추출합니다.
4. RGB, Lab, HSV 색상 지표를 계산합니다.
5. Lab 색상값으로 웜톤과 쿨톤을 구분합니다.
6. 밝기를 이용해 봄·가을 또는 여름·겨울을 구분합니다.
7. 타입별 대표 팔레트와 메이크업 색상을 반환합니다.

## 결과 유형

| 유형 | 추천 예시 |
|---|---|
| 봄 웜톤 | 코랄 피치, 살구 코랄, 골든 베이지 |
| 여름 쿨톤 | 로즈 핑크, 라벤더 핑크, 소프트 모브 |
| 가을 웜톤 | 브릭 레드, 테라코타, 웜 브라운 |
| 겨울 쿨톤 | 체리 레드, 쿨 베리, 딥 플럼 |

## 한계

- 조명과 카메라 화이트밸런스에 영향을 받습니다.
- 전문 퍼스널컬러 진단을 대체하지 않습니다.
- 현장 조명에서 실제 참가자 테스트 후 기준값 조정이 필요합니다.
