# API 명세

## 상태 확인

### `GET /health`

서버 상태와 현재 가상 메이크업 공급자를 반환합니다.

## 퍼스널컬러 분석

### `POST /api/v1/analyses`

`multipart/form-data` 요청입니다.

| 필드 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `image` | JPG/PNG 파일 | 예 | 정면 얼굴 사진 |
| `consent` | boolean | 예 | 얼굴 이미지 처리 동의 |

응답에는 분석 ID, 만료 시각, 계절 타입, 언더톤, 신뢰도, 측정 피부색, 추천 팔레트 및 메이크업 색상이 포함됩니다.

### `GET /api/v1/analyses/{analysis_id}`

분석 결과를 다시 조회합니다.

### `GET /api/v1/analyses/{analysis_id}/image`

Before 이미지로 사용할 원본 사진을 반환합니다.

## 가상 메이크업

### `POST /api/v1/try-ons`

```json
{
  "analysis_id": "분석 ID",
  "lip_color": "#FF6F61",
  "blush_color": "#F6A57A",
  "eye_color": "#C99152",
  "intensity": 55
}
```

색상을 생략하면 분석 결과의 추천색을 사용합니다. 강도 범위는 0~100입니다.

### `GET /api/v1/try-ons/{try_on_id}`

처리 상태와 Before/After 이미지 URL을 반환합니다.

### `GET /api/v1/try-ons/{try_on_id}/image`

메이크업 적용 결과 이미지를 반환합니다.

## 삭제

### `DELETE /api/v1/analyses/{analysis_id}`

원본 이미지, 분석 결과 및 연결된 가상 메이크업 결과를 삭제합니다.

## 부스 제품 추천

### `GET /api/v1/analyses/{analysis_id}/products`

퍼스널컬러 유형과 추천색의 RGB 거리를 기준으로 부스 제품을 정렬하고 `match_score`를 반환합니다.

### `GET /api/v1/products`

전체 활성 제품을 조회합니다. `season`과 `category` 필터를 사용할 수 있습니다.

## 결과 공유와 QR

### `POST /api/v1/analyses/{analysis_id}/share`

얼굴 사진을 포함하지 않는 만료형 결과 링크와 QR 이미지 URL을 생성합니다.

### `GET /api/v1/public/results/{token}`

퍼스널컬러, 팔레트, 추천색과 매칭 제품을 조회합니다.

### `GET /api/v1/public/results/{token}/qr`

결과 링크가 담긴 QR PNG를 반환합니다.

## 운영자

`X-Admin-Token` 인증이 필요합니다.

- `GET /api/v1/admin/stats`: 처리량, 실패 수, 유형별 통계, 처리 대기 현황
- `PUT /api/v1/admin/products/{product_id}`: 제품 등록 또는 수정
- `POST /api/v1/admin/cleanup`: 만료 이미지와 공유 링크 정리

## 주요 오류 코드

| 코드 | 의미 |
|---|---|
| 400 | 얼굴 이미지 처리 미동의 |
| 404 | 결과 없음 또는 만료 |
| 413 | 파일 용량 초과 |
| 415 | 지원하지 않는 파일 형식 |
| 422 | 얼굴 미검출 또는 요청값 오류 |
| 502 | 외부 가상 메이크업 실패 |
| 429 | 분당 요청 제한 초과 |

실행 중 `http://localhost:8000/docs`에서 전체 요청·응답 모델을 확인할 수 있습니다.
