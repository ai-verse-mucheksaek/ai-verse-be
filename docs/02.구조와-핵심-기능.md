# 구조와 핵심 기능

## 전체 흐름

```text
얼굴 이미지 + 처리 동의
        ↓
형식·용량·해상도 검증
        ↓
정면 얼굴 검출
        ↓
이마·양 볼 피부색 추출
        ↓
퍼스널컬러 분류
        ↓
립·블러셔·아이 색상 추천
        ↓
로컬 데모 또는 Perfect Corp 가상 메이크업
        ↓
Before/After 결과 제공
        ↓
즉시 삭제 또는 보관 기간 만료 후 삭제
```

## 백엔드 구조

```text
app/
├─ main.py                  API와 서버 시작점
├─ config.py                환경 변수
├─ db.py                    SQLite 저장
├─ schemas.py               요청·응답 형식
└─ services/
   ├─ color_analysis.py     얼굴 검출과 색상 분석
   ├─ storage.py            이미지 저장·검증·삭제
   └─ virtual_tryon.py      로컬/Perfect Corp 가상 메이크업
```

## 구현된 핵심 기능

- JPG/PNG 업로드 및 개인정보 처리 동의 확인
- 파일 크기와 해상도 검증
- OpenCV 정면 얼굴 검출
- 얼굴 피부색 표본 추출
- 사계절 퍼스널컬러 분류
- 메이크업 색상 추천
- 로컬 가상 메이크업 결과 생성
- 원본과 결과 이미지 URL 제공
- 기본 24시간 보관 및 즉시 삭제
