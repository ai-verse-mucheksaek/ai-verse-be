# 구현 현황과 남은 과제

## 완료

- 얼굴 이미지 업로드와 동의 확인
- 이미지 형식·용량·해상도 검증
- 정면 얼굴 검출과 피부색 표본 추출
- 웜/쿨 및 사계절 타입 분류
- 립·블러셔·아이 컬러 추천
- 로컬 가상 메이크업 데모
- Before/After 이미지 API
- SQLite 저장, 자동 만료, 즉시 삭제
- Docker 실행 환경과 OpenAPI 문서
- 자동 테스트 4개 통과
- 만료형 결과 공유 링크와 QR PNG
- 부스 제품 카탈로그와 색상 유사도 매칭
- 관리자 처리 통계와 제품 수정 API
- 동시 가상 메이크업 처리 제한 및 대기 현황
- 분당 요청 제한과 요청 ID
- IP·얼굴 정보를 저장하지 않는 구조화 접근 로그
- 서버 실행 중 주기적 만료 데이터 정리
