# 개발 및 실행 가이드

## 로컬 실행

```powershell
Copy-Item .env.example .env
uv sync
uv run uvicorn app.main:app --reload
```

- API 문서: `http://localhost:8000/docs`
- 상태 확인: `http://localhost:8000/health`

## 자동 테스트

```powershell
uv run pytest -q
```

현재 동의 검증, 잘못된 파일 거부, 상태 확인, 분석부터 삭제까지의 전체 흐름 테스트가 구현되어 있습니다.

## Docker 실행

```powershell
Copy-Item .env.example .env
docker compose up --build
```

## 주요 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PHOTO_TTL_HOURS` | 24 | 이미지 보관 시간 |
| `MAX_UPLOAD_MB` | 10 | 최대 업로드 크기 |
| `VTO_PROVIDER` | `mock` | 가상 메이크업 공급자 |
| `PERFECTCORP_API_KEY` | 없음 | 실제 외부 API 키 |
| `ADMIN_TOKEN` | 없음 | 정리 API 관리자 토큰 |

## Perfect Corp 사용

```dotenv
VTO_PROVIDER=perfectcorp
PERFECTCORP_API_KEY=발급받은_API_KEY
```

실제 사용 전 계정 권한, API 유닛, 허용 패턴명을 확인하고 통합 테스트해야 합니다.
