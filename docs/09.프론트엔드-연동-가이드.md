# 프런트엔드 연동 가이드

## 권장 화면 순서

1. 부스 소개
2. 촬영 및 개인정보 처리 동의
3. 분석 중 화면
4. 퍼스널컬러 결과와 추천 팔레트
5. 메이크업 색상 선택
6. 가상 메이크업 처리
7. Before/After 비교
8. 실제 제품 발색 안내
9. 다음 참가자를 위한 초기화

## API 연결 순서

1. 카메라 이미지를 `POST /api/v1/analyses`로 전송합니다.
2. 응답에서 계절 타입과 추천색을 표시합니다.
3. 사용자가 색상을 선택하면 `POST /api/v1/try-ons`를 호출합니다.
4. `before_image_url`과 `result_image_url`을 비교 화면에 표시합니다.
5. 체험 종료 시 `DELETE /api/v1/analyses/{analysis_id}`를 호출합니다.

## 추가 화면 연결

- 제품 진열 안내: `GET /api/v1/analyses/{analysis_id}/products`
- QR 결과 발급: `POST /api/v1/analyses/{analysis_id}/share`
- 운영자 통계: `GET /api/v1/admin/stats`와 `X-Admin-Token`
- 처리 대기 현황: `/health` 또는 관리자 통계의 `try_on_queue`

## 화면에서 반드시 표시할 내용

- 조명과 카메라에 따라 결과가 달라질 수 있다는 안내
- 체험용 추천이며 전문 진단이 아니라는 안내
- 사진 처리 동의와 삭제 시점
- 오류 발생 시 재촬영 방법
