# 예뻐질 사람? It's Me!

## 프로젝트명

AI 퍼스널컬러 분석 및 가상 메이크업 체험

## 목적

방문 학생의 얼굴 사진을 분석하여 퍼스널컬러를 안내하고, 어울리는 립·블러셔·아이 메이크업 색상을 추천한 뒤 가상으로 적용해보는 부스용 서비스입니다.

## 체험 순서

1. 얼굴 사진 촬영 및 이미지 처리 동의
2. 얼굴 검출과 피부색 분석
3. 봄·여름·가을·겨울 퍼스널컬러 결과 확인
4. 립·블러셔·아이 메이크업 색상 추천
5. 가상 메이크업 적용
6. Before/After 비교
7. 부스에 준비된 실제 제품 발색

## 현재 개발 범위

백엔드 MVP가 구현되어 있습니다. 이미지 업로드, 색상 분석, 추천, 로컬 가상 메이크업, 결과 조회 및 삭제가 가능합니다. Perfect Corp API는 연동 코드까지 작성되어 있으나 실제 API 키를 이용한 검증이 필요합니다. 촬영 및 결과 화면은 별도 프런트엔드 개발이 필요합니다.
