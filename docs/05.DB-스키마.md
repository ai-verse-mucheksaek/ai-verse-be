# DB 스키마

SQLite 파일에 참가자 이름이나 연락처 없이 분석 및 처리 상태만 저장합니다.

## `analyses`

| 컬럼 | 설명 |
|---|---|
| `id` | 분석 임의 ID |
| `created_at` | 생성 시각 |
| `expires_at` | 자동 삭제 기준 시각 |
| `status` | 처리 중, 완료, 실패 상태 |
| `original_path` | 원본 이미지 내부 경로 |
| `result_json` | 퍼스널컬러와 추천 결과 |
| `error` | 실패 메시지 |

## `try_ons`

| 컬럼 | 설명 |
|---|---|
| `id` | 가상 메이크업 임의 ID |
| `analysis_id` | 연결된 분석 ID |
| `created_at` | 생성 시각 |
| `status` | 처리 상태 |
| `provider` | `mock` 또는 `perfectcorp` |
| `provider_task_id` | 외부 API 작업 ID |
| `result_path` | 결과 이미지 내부 경로 |
| `request_json` | 선택 색상과 강도 |
| `error` | 실패 메시지 |

분석을 삭제하면 연결된 가상 메이크업 기록과 이미지도 함께 삭제됩니다.

## `products`

부스에 비치한 립·블러셔·아이 제품의 이름, 브랜드, 색상, 추천 계절 유형과 테스터 라벨을 저장합니다. 제품을 제거하지 않고 `active` 값으로 사용 여부를 관리할 수 있습니다.

## `share_links`

분석 결과 QR에 사용하는 임의 토큰과 만료 시각을 저장합니다. 얼굴 이미지 URL은 공유 결과에 포함하지 않으며 분석 삭제 시 공유 링크도 함께 삭제됩니다.
