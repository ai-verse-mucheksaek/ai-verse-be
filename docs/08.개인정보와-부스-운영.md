# 개인정보와 부스 운영

## 개인정보 처리

- 얼굴 사진 촬영 전에 수집·처리 동의를 받습니다.
- 참가자의 이름, 이메일, 연락처는 수집하지 않습니다.
- 원본과 결과 이미지는 기본 24시간 뒤 삭제합니다.
- 참가자가 요청하면 분석 ID를 기준으로 즉시 삭제할 수 있습니다.
- Perfect Corp 사용 시 외부 전송 여부와 공급사 보관 기간을 동의문에 반영해야 합니다.

## 촬영 환경

- 얼굴 전체가 보이는 정면 사진을 촬영합니다.
- 한 번에 한 사람만 촬영합니다.
- 좌우 조명 밝기를 일정하게 유지합니다.
- 카메라 필터와 미용 보정을 끕니다.
- 모든 참가자가 같은 위치와 거리에서 촬영하도록 안내합니다.

## 서버 운영

- 행사 전에 관리자 토큰을 변경합니다.
- 실제 운영에서는 HTTPS를 사용합니다.
- 프런트엔드 주소만 CORS에 등록합니다.
- API 키를 소스 코드나 참가자 화면에 노출하지 않습니다.
- 행사 종료 후 저장 폴더에 이미지가 남아 있지 않은지 확인합니다.
